Fictional Cedarline Cloud documentation.

## Policy and procedure

Owners and admins create scoped API tokens in Settings > Developer. Tokens are displayed once and expire after 90 days. Revoke a compromised token immediately. Do not place tokens in browser JavaScript, public repositories, screenshots, or support tickets.
