# Troubleshoot E-104

Category: Troubleshooting
Effective: 2026-10-01 unless another date is explicitly stated below.
Fictional Cedarline Cloud documentation.

## Policy and procedure

Error E-104 means your login session expired. Sign out, close other Cedarline tabs, and sign in again. If the error persists, clear Cedarline site data. This does not delete cloud files but can remove unsent local drafts. Save draft text first.
