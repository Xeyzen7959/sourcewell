# Troubleshoot E-207

Category: Troubleshooting
Effective: 2026-10-01 unless another date is explicitly stated below.
Fictional Cedarline Cloud documentation.

## Policy and procedure

Error E-207 means an upload exceeds the plan file-size limit. Starter allows 25 MB per file; Studio allows 100 MB. Compress the file or split it into smaller files. A workspace owner can upgrade the plan if the larger limit is needed.
