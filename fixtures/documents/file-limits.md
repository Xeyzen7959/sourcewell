# File upload limits

Category: Product
Effective: 2026-10-01 unless another date is explicitly stated below.
Fictional Cedarline Cloud documentation.

## Policy and procedure

Starter supports files up to 25 MB each and 10 GB of total workspace storage. Studio supports files up to 100 MB each and 100 GB total. Executable files are blocked. A workspace that reaches its storage cap can still read and download existing files.
